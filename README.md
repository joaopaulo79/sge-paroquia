# Guia de configuração

Ao clonar o repositório, clique com o botão direiro no projeto no eclipse, e selecione Maven -> Update Project

Após isso, certifique-se que o banco está configurado corretamente

Os parâmetros são:
- nome do bd: sgeParoquia
- porta: 3306
- user: root
- senha: **em branco**

## Para executar o projeto
- Clique direito no método **main** da classe Main
- Run As -> Maven Build
- No campo goals, adicione **javafx:run**
